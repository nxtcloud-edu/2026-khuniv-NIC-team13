3D 평가체계(X·Y·Z 축)을 경영·영업·마케팅 직무(인문/상경 계열)와 연구개발·생산 직무(이공계 계열)로 따로 구분하여 정리한 평가기준은 다음과 같음.
점수 범위는 1.0~5.0이며, 필요 시 0.1 단위로 세분화가 가능.
•	X축 = 학습 수준(이론·실무 학습 정도)
•	Y축 = 직무 적합성(직무와의 연관성·프로젝트 리더 경험 등)
•	Z축 = 수행 역량(구체적 성과·실무 기여도)

o	R&D/생산 직무: 창업 아이템이 기술 기반이면, 특허·논문·R&D 성과와 연계하여 고득점 가능.
2.	부트캠프, 기업 연계 교육
o	학습 수준(X축)에 0.1~0.2 가산. 실무 프로젝트로 이어졌다면 Y·Z에도 추가 소폭 가산(구체 성과 입증 시).
3.	특허
o	연구개발(이공계): 특허 등록 → X축 4.4~4.9 이상, 수행 역량(Z) 4.4 이상 달성 가능 근거.
o	경영(상경계): 특허가 마케팅 전략, 비즈니스 모델과 직결되면 Y·Z축 가산.
4.	논문 (학술지·학술대회 발표)
o	SCI/SCIE/SSCI/SCOPUS 등급, 국제 학술대회 vs 국내 학술대회에 따라 **학습 수준(X)**이 크게 좌우.
o	직무와 직접 연관된 논문이면 Y축에서도 가산. 실무 프로젝트와 결합된 논문이면 Z축에도 영향.
5.	가산점 & 0.1 단위 정밀 평가
o	각 축을 1.0~5.0 범위로 기본 점수 매긴 후 특수 경험(창업, 특허, 부트갬프 등)을 고려해 +0.1~+0.3 조정 가능.

최종 활용 방법
•	X·Y·Z 각각 1.0~5.0으로 평가: 지원자의 학습 수준(이론+실무), 직무 적합성(프로젝트 리더 경험, 직무 경험), 수행 역량(구체적 성과)을 정량화.
•	필요 시 0.1 단위로 세분화: 예) X=4.3, Y=3.9, Z=4.1
•	기업마다 우선순위·가중치 조정 가능: R&D 위주 기업은 X·Z 비중을 높게, 영업·마케팅 중시 기업은 Y·Z 비중을 높게 두는 식.
•	학술지·창업·특허 등 추가 요소는 각 축에서 가산점으로 반영해, 지원자의 특별 성과나 부트캠프/창업 이력을 평가에 포함.
위 기준을 통해, 경영·영업·마케팅 직무와 연구개발·생산 직무를 구분한 체계적 평가를 진행하여 지원자의 역량을 객관적·정량적으로 파악할 것.
