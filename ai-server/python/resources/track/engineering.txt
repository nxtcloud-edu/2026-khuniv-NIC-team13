X축 평가 기준 정의


[5.0 (최고 수준)] 조건/예시 : - SCI/SCIE 논문 발표- 세계적 학술지 게재 또는 글로벌 특허 등록- 공정/제품/시스템/알고리즘 구조 설계 경험- 변수 기반 문제 모델링 및 실험/설계 수행- 병목, 변수, 트레이드오프, 확장성 설명 가능[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한
설명 : 최고 수준이다. 기술을 단순히 알고 있는 것이 아니라, 문제를 구조화하고 모델·가설·실험·시스템 설계로 전환할 수 있는 상태다. 이 수준의 지원자는 “문제를 어떻게 설계할 것인가”를 설명할 수 있다. 평가 판단 포인트 : 다음 조건을 모두 충족할 경우 5.0으로 판정한다.- 변수 정의 존재- 인과관계 설명 가능- 실험, 공정 또는 시스템 설계 경험 존재- 설계 선택 근거 설명 가능- KPI를 설계 단계에서 고려함하나라도 미충족이면 4.9 이하로 하향한다.


[4.7 ~ 4.9] 조건/예시 : - 핵심 기술/공정/시스템 설계 참여- 데이터 기반 분석 경험- 성능/수율/정확도 개선 설계 경험- 구조 기반 해석 가능
설명 : 고급 수준의 기술적 사고를 갖춘 상태다. 핵심 설계와 분석을 수행할 수 있으며 구조 이해도가 높다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 구조 기반 해석 가능- 설계 또는 분석 경험 존재- 성능, 수율, 정확도 개선 경험 존재전체 시스템을 독립 설계한 근거가 없으면 5.0으로 상향하지 않는다.

설명 : 실무 적용 가능한 수준이다. 기능 구현이나 분석 수행을 넘어 구조 이해가 있는 상태다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 분석 또는 구현 경험 존재- 구조 이해 존재다음 조건 시 4.3 이하로 하향한다.- 단순 구현 수준- 설계 근거 없음


[4.1 ~ 4.3] 조건/예시 : - 실험 경험- 개발/공정/품질 프로젝트 수행 경험[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 설명 : 기본 수준이다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 실험 또는 개발 경험 존재- 적용은 가능하나 구조 설명이 약함
