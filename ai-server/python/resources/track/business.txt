① Business Track (경영·영업·마케팅 계열): 시장·고객·수익모델·KPI 기반 전략 설계 및 실행 역량 평가


X축 평가 지표 정의


[5.0 (최고 수준)] 조건/예시 : - SSCI 논문 발표- 세계적 학술지(A&HCI급 포함)에 경영/마케팅 논문 게재- 최고 수준 자격증(CFA Lv.3, CPA 등) 보유- 시장·고객·수익모델·KPI를 하나의 전략 모델로 설계한 경험- STP, 4P, LTV/CAC, Funnel, TAM/SAM/SOM 등을 통합적으로 적용한 경험
설명 : 최고 수준의 이론·실무 지식 보유 상태다. 단순히 지식을 많이 보유한 것이 아니라, 시장 구조를 분석하고 고객과 성과를 연결하며, 실행 가능한 전략 프레임을 설계할 수 있는 상태다. 이 수준의 지원자는 시장을 “정보”가 아니라 “구조”로 이해하며, 전략을 “아이디어”가 아니라 “설계 모델”로 다룰 수 있다. 평가 판단 포인트 : 다음 조건을 모두 충족할 경우 5.0으로 판정한다.- 시장 구조 분석 존재- 고객 세분화 및 행동 구조 정의 존재- KPI(CAC, LTV 등) 설계 포함- 전략 선택 근거 및 트레이드오프 설명 가능- 시장-고객-수익-성과가 하나의 구조로 연결됨다음 조건 중 하나라도 미충족이면 4.9 이하로 하향한다.- KPI 구조 부재- 전략 설계 근거 없음- 실행 경험만 있고 구조 설계 없음


[4.7 ~ 4.9] 조건/예시 : - SSCI/SCI급 학술지 발표 경험- 글로벌 공모전 우승- CFA Lv.2, 광고/PR 고급 자격증 보유- STP, 4P, 고객 세분화, TAM/SAM/SOM 구조를 활용한 전략 설계 경험- KPI 기반 전략 수정 경험
설명 : 고급 수준의 이론과 실무 이해를 기반으로 전략 프로젝트를 리드하거나, 최소한 핵심 전략 구조를 설계할 수 있는 수준이다. 고객, 시장, 채널, 성과지표를 연결해 의사결정을 내릴 수 있다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- STP, 4P 등 전략 도구의 실제 적용 경험 존재- 고객 세분화 기준이 명확함- KPI가 전략 설계 또는 수정에 반영됨- 데이터 기반 의사결정 경험 존재다음 조건 시 4.6 이하로 하향한다.- 전략 도구 사용은 있으나 실제 적용 근거 없음- KPI와 전략 연결이 없음


[4.4 ~ 4.6] 조건/예시 : - SCIE 등재 논문 발표- 국내 유명 학술지 논문 게재- L’Oreal Brandstorm 등 대형 공모전 수상- 고객 Journey, Value Proposition, Funnel 구조를 활용한 실무 프로젝트 수행- 시장 데이터 기반 캠페인 설계 또는 실행[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한
설명 : 실무 기법 숙달 수준이다. 시장·고객 분석 결과를 실행 가능한 전략으로 연결할 수 있으며, 프로젝트 성과 창출에 실질적으로 기여할 수 있다. 다만 전략 전체를 독립적으로 설계하는 수준까지는 아닐 수 있다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 고객 분석 경험 존재- 실행 경험 존재- KPI 일부 존재 또는 결과 수치 일부 제시다음 조건 시 4.3 이하로 하향한다.- KPI 없음- 고객 구조 설명 불가- 채널 또는 메시지 선택 근거 없음


[4.1 ~ 4.3] 조건/예시 : - 국제 학술대회 발표- 국내 학술지·공모전 참가 경험- 마케팅 분석 툴 활용 경험- 디지털 마케팅, CRM, 리서치 프로젝트 참여
설명 : 경영·마케팅 이론을 실무에 활용할 기초 역량을 갖춘 상태다. 전략 모델을 이해하고 일부 요소를 적용할 수 있으나, 독립적 설계 수준은 제한적이다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 이론 이해 존재- 일부 실무 적용 경험 존재다음 조건 시 4.0 이하로 제한한다.- 전략 구조 설계 경험 없음- KPI 연결 없음


[3.7 ~ 4.0] 조건/예시 : - 국내 학술대회 발표- 관련 자격증(SQLD, 마케팅 분석 등) 취득- 실무 프로젝트 경험- 홍보, SNS 운영, 콘텐츠 기획 경험
설명 : 팀 내 일정 부분 성과를 낼 수 있는 실무 역량이다. 이론 이해와 기본 실행은 가능하나 전략 구조 설계는 아직 약한 단계다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 실행 경험 존재- KPI 없음 또는 매우 제한적- 전략 설계 근거 없음


[3.4 ~ 3.6] 조건/예시 : - 경영/마케팅 인턴십 또는 프로젝트 참여- 일반 공모전 참가- 단순 홍보/운영 경험
설명 : 기초 학습을 통해 제한적 성과 가능하다. 실무 보조 역할 수행에 적합하다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 참여 경험 중심임- 역할이 보조적임- 전략 선택 근거가 제시되지 않음


[3.1 ~ 3.3] 조건/예시 : - 경영/마케팅 프로젝트 일부 보조 역할
설명 : 기초 학습 수준이다. 단순 보조적 기여 가능 수준이다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 프로젝트 일부 보조 역할 수행- 본인 주도성 낮음- 결과가 팀 단위로만 제시됨[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한


[2.7 ~ 3.0] 조건/예시 : - 관련 교육 이수 또는 기초 프로젝트 경험 설명 : 제한적 성과만 기대 가능하며 실무 지식이 부족한 상태다. 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 관련 교육 이수는 있으나 실행 연결이 부족함- 이론 중심 경험만 존재함

[1.0 ~ 1.9] 조건/예시 : - 관련 학습 경험 전무[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 설명 : 직무 수행 준비가 전혀 되지 않은 상태다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- 관련 학습과 경험이 모두 없음[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한

[5.0 (최고)] 조건/예시 : - 글로벌 기업 핵심 프로젝트 리더 경험- SSCI 논문 발표 또는 주요 경영 프로젝트 핵심 성과- 시장 분석 → 전략 수립 → 실행 → KPI 검증 → 개선의 전체 Flow 주도- 매출/전환율/ROI 등 성과 책임 경험- Role/Skill/Domain/Behavior가 모두 매우 높게 일치
설명 : 조직 목표 달성에 주도적 역할 수행이 가능한 수준이다. 단순 관련 경험이 아니라 직무 Flow 전체 파트를 재현할 수 있는 구조적 적합성을 갖춘 상태다. 단순 실행자가 아니라 전략 설계, 자원 배분, KPI 추적, 개선까지 가능한 상태다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 4요소를 모두 충족할 경우 5.0으로 판정한다.- Role: 핵심 책임 또는 리더 수행- Skill: 직무 핵심 기술 직접 활용- Domain: 산업 구조 이해 및 적용- Behavior: KPI 기반 의사결정 수행하나라도 현저히 약하면 4.9 이하로 하향한다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한


[4.7 ~ 4.9] 조건/예시 : - SSCI/SCI급 논문 발표 경험- 글로벌/대기업 프로젝트 리더 경험- 고객·시장·채널·성과지표를 연결한 실행 경험- 데이터 기반 의사결정 수행 경험[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한
설명 : 고도의 문제 해결 능력과 실행 역량을 바탕으로 프로젝트 리더 역할 수행 잠재력이 충분하다. 직무 핵심 역할과 Skill 정합성이 높은 상태다.[Gate]- KPI 없음 → 상위 점수 제한- 구조/Role/Domain 미충족 → 상위 점수 제한[Cap]- 재현성/Loop 부족 → 상한 제한 평가 판단 포인트 : 다음 조건을 충족하면 해당 구간으로 판정한다.- Role과 Skill 일치도가 높음- Domain 이해가 충분함- 데이터 기반 실행 경험 존재다음 조건 시 4.6 이하로 하향한다.- KPI 책임 없음- 전략을 완전히 설계한 근거 없음
