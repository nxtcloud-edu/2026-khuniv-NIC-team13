Y축(직무적합 수준)에 대한 설명이다.

Y축은 '이 지원자가 이 직무에 딱 맞는 사람인가?'를 4가지 요소로 평가합니다.
점수는 Role + Skill + Domain + Behavior를 평균한 점수이다.
다시 말하면 (역할 적합성 + 기술 적합성 + 도메인 이해 + 행동 적합성) / 4 로 점수를 산정한다.

Role : 역할 적합성, 이 직무의 역할을 직접 해봤나요?, "이 사람이 그 역할을 실제로 수행한 적 있는가?"
5.0점 → 그 직무를 이끄는 리더 역할을 해봤다
4.5점 → 핵심 역할을 혼자 수행해봤다
4.0점 → 부분적인 역할을 수행해봤다
3.0점 → 보조 역할만 했다
2.0점 → 관련 경험이 없다
주의:  '관심 있다', '배우고 싶다' → 경험으로 인정 안 됨

Skill : 기술 적합성, 필요한 기술을 실제로 쓸 수 있나요?, "배웠다가 아니라, 실제 업무에 쓸 수 있는가?"
5.0점 → 핵심 기술을 완전히 숙련해서 쓸 수 있다
4.5점 → 실무에 바로 투입 가능한 수준
4.0점 → 프로젝트에서 써본 경험이 있다
3.0점 → 기초 수준 (교육에서만 배움)
2.0점 → 없음
주의:  '배웠다', '알고 있다' → Skill 높게 주면 안 됨

Domain : 도메인 이해, 이 산업/분야를 구조적으로 이해하나요?, "이 분야가 어떻게 돌아가는지 설명할 수 있는가?"
5.0점 → 산업 구조 + 핵심 변수 + 전체 흐름을 설명 가능
4.5점 → 주요 프로세스를 이해함
4.0점 → 개념은 알지만 구조 설명이 약함
3.0점 → 용어는 알지만 단편적 지식
2.0점 → 없음
주의:  '이 분야 관심 있음' → Domain 점수 주면 안 됨

Behavior : 행동 적합성, 일하는 방식이 이 직무에 맞나요?, "이 조직의 방식으로 일할 수 있는가?"
5.0점 → 팀을 이끌며 데이터 기반으로 의사결정함
4.5점 → 협업 및 실행 능력이 뛰어남
4.0점 → 기본적인 협업은 가능함
3.0점 → 지시받아서 수행하는 수동적 스타일
2.0점 → 조직 방식에 적합하지 않음
주의:  '성격 좋음', '친화력 있음' → Behavior 점수 아님

Y 축에 대한 점수 산정 기준은 아래와 같다.
- 5.0(이 직무의 실행 구조 전체를 재현 가능한 수준) : 핵심 프로젝트 리더 경험, KPI 기반 의사결정 수행, Role/Skill/Domain/Behavior 모두 높음, 4가지 요소 모두 충족, KPI 기반 의사결정 경험. 하나라도 약하면 4.9 이하
- 4.7~4.9(프로젝트 리더로 활약 가능한 고급 수준) : 대기업/주요 프로젝트 리더 경험, 데이터 기반 실행 경험, Role과 Skill 일치도 높음, 데이터 기반 실행 경험 있음
- 4.4~4.6(실질적으로 기여할 수 있는 고급 실무 수준) : 주요 프로젝트에서 실질 기여, 직무 관련 데이터 분석 경험, 핵심 기여 경험 있음, KPI 일부 기여 있음, KPI 없으면 4.3 이하
- 4.1~4.3(실무에서 일부 기여할 수 있는 기초 실무 수준) : 직무 관련 프로젝트 수행, 관련 학술대회 발표 경험, 직무 관련 경험 있음, 역할/기술/산업 일부만 일치
- 3.7~4.0(기본 직무 수행은 가능한 수준) : 보조 역할 참여, 운영, 홍보 경험, 보조적 실행 경험 중심, Role 또는 Skill이 부분적
- 1.0~3.6(기초 수준 또는 직무 경험 없음) : 인턴십 기초 역할, 관련 경험 없음, 독립 수행 어려움, KPI 없음
