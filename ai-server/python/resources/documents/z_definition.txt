Z축(수행 역량)에 대한 설명이다.

Z축은 '이 사람이 실제로 성과를 냈는가?'를 보는데, 단순히 결과가 있는지를 보는 게 아니다. 성과를 만들어낸 구조가 있는지, 반복할 수 있는지, 확장할 수 있는지를 본다.

Z축 점수 계산 공식
Z = (기여도 × 0.35) + (재현성 × 0.30) + (확장성 × 0.35)
단, 이 공식을 적용하기 전에 Execution Loop → Cap → Gate 순서로 먼저 확인해야 한다.

ACI 기여도 지수 : 이 성과를 낸 것이 본인인가?
RI 재현성 지수 : 같은 성과를 다시 낼 수 있는가?
ISI 확장성 지수 : 이 성과를 다른 곳에도 쓸 수 있는가?

Execution Loop — 실행 반복 구조 '문제를 해결하는 과정을 얼마나 체계적으로 반복했는가'를 보는 개념이다.

Loop 6단계 구조는 아래와 같다.
1단계: 문제 정의  →  '어떤 문제를 해결하려 했는가?'
2단계: 가설 설정  →  '어떤 방법으로 해결할 것인가?'
3단계: 실행       →  '실제로 해봤는가?'
4단계: 측정       →  '결과를 수치로 확인했는가?'
5단계: 개선       →  '결과를 보고 수정·보완했는가?'
6단계: 재적용     →  '개선된 방법을 다시 적용했는가?'

3단계 이하 : 단발성 수행 (한 번 해보고 끝) Z ≤ 3.9점 "해봤습니다" 수준
4단계 : 측정까지 해봄 (1회 개선 구조) Z ≤ 4.1점 "결과를 확인했습니다" 수준
5단계 : 반복 개선 가능 Z ≤ 4.3점 "수정하고 다시 해봤습니다" 수준
6단계 : 자동화/재사용 구조 보유 Z ≥ 4.4점 가능 "다른 곳에도 적용했습니다" 수준

프로젝트를 한 번 진행하고 결과물만 낸 것은 Execution Loop가 아닙니다.
최소 2회 이상 반복하고, 개선한 기록이 있어야 Loop로 인정합니다.

Cap 조건 : 역할에 따른 점수 상한, 지원자가 어떤 역할을 했느냐에 따라 점수 상한이 달라집니다. 아무리 좋은 경험이 많아도, 역할이 보조 수준이면 높은 점수를 줄 수 없습니다.
Support (보조) : 전체 구조 설계 경험 없이 실행을 도왔을 뿐, 4.1점 상한 (데이터 수집, 자료 정리, 보조 실험)
Partial (부분 책임) : 일부 기능이나 모듈은 책임졌지만 전체는 아님, 4.3점 상한 (특정 기능 개발, 부분 실험 설계)
Owner (전체 책임) : 전체 설계·실행·개선을 모두 책임짐, 제한 없음(Gate 충족 필수, 시스템 전체 설계, KPI 책임 경험)

Gate 조건 : Z ≥ 4.5 진입 조건 (3가지 모두 충족해야 함)
① ACI ≥ 4.5  →  본인이 핵심 수행자여야 함 (보조 역할이면 불가)
② RI  ≥ 4.5  →  결과를 재현할 수 있어야 함 ("어떻게 했는지" 설명 가능)
③ ISI ≥ 4.5  →  산업이나 다른 서비스에 적용 가능해야 함
셋 중 하나라도 4.5 미만이면 Z 4.5점 진입은 불가합니다.

Z 축에 대한 점수 산정 기준은 아래와 같다.
5.0(성과를 구조화해서 반복·확장 가능한 최고 수준) : 글로벌 프로젝트 리더, KPI 전후 비교 명확, 실행 Loop 전체 설계 + 반복 개선, ACI/RI/ISI 모두 높음, KPI 명확, Execution Loop 존재, ACI/RI/ISI 모두 충족. 하나라도 없으면 4.9 이하
4.7~4.9(리더로 활약 가능하고 반복 실행이 확인된 수준) : 주요 실무에서 실질 성과, KPI 기반 결과 증명, 재실행 가능한 구조 보유, KPI 존재, 실행 구조 존재, 반복 수행/개선 경험. 확장성 없으면 4.6 이하
4.4~4.6(성과는 있지만 재현성·확장성이 부분적인 수준) : 기업 실무에서 성과 기여, KPI 일부 증명, 실행 및 일부 개선 경험, KPI 일부 존재, 실행 경험 있음. Loop 없으면 4.3 이하
4.1~4.3(성과는 있지만 구조·반복 설명이 약한 수준) : 실무 보조 이상 성과 기여, 실행 경험 있으나 KPI 부분적, 실행 경험 있음, KPI 또는 재현성 설명 부분적
3.7~4.0(기본 수행은 하지만 Loop가 단발성인 수준) : 프로젝트에서 일정 성과, Loop가 단발성, 일정 성과 있음, Loop 구조는 단발성에 가까움
1.0~3.6(보조 역할이거나 경험이 거의 없는 수준) : 보조 역할, 단순 참여, 무경험, Loop/KPI/재현성 모두 약함
