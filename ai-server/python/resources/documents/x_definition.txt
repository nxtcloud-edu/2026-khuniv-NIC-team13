X축(학습 수준)에 대한 설명이다.

X축은 단순히 '많이 공부했는가'를 보는 게 아니다. 배운 것을 실제로 써먹을 수 있는 구조로 만들 수 있는지를 본다.

X축에서 확인하는 역량은 아래와 같다.
- 이론을 실제 문제에 적용할 수 있는가?
- 변수(원인)와 결과를 연결해서 설명할 수 있는가?
- 왜 이 방법을 선택했는지 근거를 댈 수 있는가?
- 데이터와 성과 지표(KPI)를 연결할 수 있는가?

X 축에 대한 점수 산정 기준은 아래와 같다.
- 5.0(이론을 직접 실행 모델로 설계한 최고 수준) : 세계적 학술지 논문 발표, 특허 등록, 전략 전체를 직접 설계하고 KPI까지 설정, 변수 정의 가능, 인과관계 설명 가능, KPI를 설계에 반영했음. 하나라도 없으면 4.9 이하
- 4.7~4.9(핵심 분석·설계를 수행할 수 있는 고급 수준) : 주요 논문 발표 경험, 핵심 기술/시스템 설계 참여, 데이터 기반 성능 개선 경험, 구조 기반 해석 가능, 설계 또는 분석 경험 있음, 성능 개선 경험 있음
- 4.4~4.6(실무에 바로 적용 가능한 수준) : 프로젝트에서 직접 분석 수행, 관련 툴 활용 경험, 데이터 분석 후 실행 연결 경험, 분석 또는 구현 경험 있음, 구조 이해 있음, 단순 구현이면 4.3 이하
- 4.1~4.3(기본은 알지만 독립 설계는 아직 어려운 수준) : 실험 또는 개발 프로젝트 참여, 이론을 일부 적용한 경험, 실험/개발 경험 있음, 구조 설명이 약하면 이 구간
- 3.7~4.0(기초 실무는 가능한 수준) : 팀 프로젝트 참여, 기본 개발 또는 실습 경험, 팀 프로젝트/실습 경험 있음, 단순 수행 중심
- 1.0~3.6(이론 중심이거나 경험이 거의 없는 수준) : 수업 이수, 교재 학습, 관련 경험 없음, 실무 연결 부족, 설계 불가
